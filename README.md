1C IBases Manager (Batch / CMD)

Набор скриптов для автоматизированного управления списком информационных баз (ibases.v8i) на компьютерах пользователей. Позволяет массово добавлять или удалять базы 1С через сетевые пути, сохраняя целостность конфигурационных файлов.



Выполненные таски:



1\. Удаление базы

Скрипт находит и корректно удаляет конкретную секцию базы из файла конфигурации.

Умный поиск: Ищет базу не по имени, а по уникальному параметру внутри секции (например, Ref="test").

Чистое удаление: Определяет границы секции (от \[...] до следующего \[...]) и вырезает её целиком.

Валидация: Проверяет файл на пустоту и корректность структуры перед записью.



2\. Добавление базы

Скрипт добавляет новую базу из шаблона (info.txt), если её еще нет у пользователя.

Защита от дублей: Проверяет наличие базы по строке подключения перед добавлением.

Безопасная запись: Использует механизм блокировки ошибок, чтобы не повредить файл, если он занят процессом.

Форматирование: Автоматически обрабатывает переносы строк, чтобы не склеить секции.



Скрипты написаны на Windows Batch (CMD).

Работают с кодировкой Windows-1251 (стандарт для v8i файлов).

Поддерживают работу с сетевыми путями (\\\\ComputerName\\C$\\...).

Включают логику обертки (wrapper) для чтения списков ПК из Excel/CSV (через check\_excel.cmd).
